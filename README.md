## 🚀 Features

- ✅ **Fully Responsive** - Optimized for desktop, tablet, and mobile devices
- ✅ **Smooth Animations** - Scroll-triggered animations using AOS library
- ✅ **Modern UI** - Clean, professional design with Tailwind CSS
- ✅ **Component-Based** - Modular React components for easy maintenance
- ✅ **Interactive Elements** - Hover effects, animated buttons, and dynamic content
- ✅ **Contact Form** - Frontend contact form with validation
- ✅ **CV Download** - Direct download functionality for resume
- ✅ **Project Showcase** - Grid layout displaying featured projects with GitHub links
- ✅ **Squiggly Line Animation** - Custom animated underline effect on hero name

## 🛠️ Technologies Used

### Frontend
- **React 18** - UI library
- **Tailwind CSS** - Styling framework
- **AOS (Animate On Scroll)** - Scroll animations
- **React Icons** - Icon library
- **Font Awesome** - Additional icons

### Development Tools
- **Vite** - Build tool and dev server
- **Git** - Version control
- **npm** - Package manager


## 💻 Installation

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn

### Steps

**Clone the repository**
git clone https://github.com/MhmdSaid212/portfolio.git
cd portfolio
npm install
npm install aos react-icons
npm run dev
